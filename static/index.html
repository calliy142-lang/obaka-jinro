    【イノセント陣営】
    
            
    勝利条件: すべてのインポスターおよび有害な第三陣営を追放・全滅させる。
    
            
      
                
    • バカ: 本人は他のイノセント役職に見えているが、能力は一切発動しない（デタラメな結果になる）。
      • 
                
    • ドクター: 選択したプレイヤーを夜の襲撃から保護する。
      • 
                
    • ポリス: 選択したプレイヤーの夜の外出（能力発動）を阻止する。
      • 
                
    • トラッパー: 選択したプレイヤーの家に罠を設置する。その家を訪問したプレイヤーの能力を失敗させる。
      • 
                
    • インベスティゲーター: 選択したプレイヤーの役職候補を調査する。
      • 
                
    • ねずみ / ルックアウト / 挑発者 / トラッカー: 各種情報収集能力。
      • 
            
    

            
    【インポスター陣営】
    
            
    勝利条件: 生存者を減らし、インポスターの人数がイノセントと同数以上になる。
    
            
      
                
    • インポスター: 毎夜1名を襲撃して殺害できる。画面上はイノセント役職（ドクター等）に偽装される。
