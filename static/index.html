ホストルーム設定

① 陣営人数（最優先）

合計を参加人数に合わせてください。まずこの人数枠を確定し、その中に個別役職を割り当てます。

0人の役職は、陣営の余った枠を埋める際にランダム候補になります。1人以上を指定した役職は、その人数を優先して配置します。

📖 役職ルール説明＆勝利条件

【イノセント】

  • バカ：イノセント役職を与えられたように見えるが、実際には能力を持たない。
  • ドクター：選択したプレイヤーが死亡した場合に蘇生。2夜連続で同じ家は訪問不可。
  • ねずみ：選択したプレイヤーの真の役職・陣営を1回だけ知る。次の昼に全員へ公表。
  • ポリス：対象の能力使用を封じる。2夜連続で同じ対象は不可。
  • トラッパー：対象の家に罠を仕掛け、訪問者のうち1人をランダムに封じる。
  • ルックアウト：対象の家を訪問した人を知る。
  • インベスティゲーター：対象の役職候補を2つに絞る。
  • 挑発者：対象の翌日の票を+2。2回使用。
  • トラッカー：対象が夜に訪れた家を確認。

【インポスター陣営】

  • インポスターは独立した役職ではなく陣営。インポスター陣営のプレイヤーは、対象となるイノセント系役職を1つ持つ。
  • 対象役職：ねずみ / ポリス / トラッパー / ルックアウト / インベスティゲーター / 挑発者 / トラッカー。
  • 対象外：バカ / ドクター。
  • ブレイマー：対象が死亡/追放された際、インポスター側の役職に見せる。2回使用。
  • クリーナー：対象が死亡/追放された際、役職を不明にする。

【ニュートラル】

  • シリアルキラー：対象を殺害。他の全員が死亡すると勝利。
  • ボマー：爆弾を設置・起爆。他の全員が死亡すると勝利。
  • サバイバー：殺害されても3回まで復活。ゲーム終了時に生存すると勝利。
  • シーフ：対象を殺害して役職を盗み、盗んだ役職の勝利条件を引き継ぐ。
  • ゴースト：ろうそくを置き、追放された場合は次の夜に対象を道連れ。
  • 魔術師：対象の役職を予想。正解なら対象死亡、外れなら自分が死亡。
